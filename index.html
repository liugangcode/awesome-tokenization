Hybrid

Neural and algorithmic components both determine one result, or distinct tokenizer types form one combined stream.

Tokenizer Completeness Check

A tokenizer has three modules. This view records whether each source defines, fixes, or reuses them.

tokenizer.trainThis module determines reusable rules or parameters.tokenizer.encodeThis module maps an input to tokens.tokenizer.decodeThis module maps tokens to the declared reconstruction.

Completeness. A complete system specifies all three modules, while a partial system specifies one or two. A reused system imports them from prior work. Mixed systems combine streams with different module status.

Module source. Developed means that the source defines or fits the module. Fixed means that no fitting is required, and reused means that the source imports the module. The decoding label states the recovery target or records that decoding is absent.
